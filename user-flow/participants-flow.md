# Флоу: Управление списком участников

Панель слева содержит карточки «Добавить участников» и «Участники».

## Добавление списком (основной способ)

1. В поле `textarea` вводится список имён — **по одному в строке** (пустые строки игнорируются).
2. Кнопка **«Добавить»** парсит строки и добавляет каждого как нового участника с весом `×1`.
3. После добавления поле очищается, а раунд и подиум сбрасываются.

> Одиночного добавления (по одному) нет — только списком.

## Список не скроллится

Список «Участники» **растягивается по высоте и показывает всех сразу** — внутреннего скролла нет (без `max-height`/`overflow`). Чем больше участников, тем длиннее левая колонка.

## Редактирование строки

Каждая строка участника поддерживает:

- **Переименование** — редактируемый `input` с именем; имя обновляется на каждый ввод.
- **Вес ×1 / ×2** — переключатель веса. Сегмент колеса рисуется **пропорционально весу** (шанс выпадения и размер сектора ×2 больше, чем ×1).
- **✋ / 🙈 (включить/выключить)** — ручной переключатель «участвует ли участник в колесе» (`enabled`). Отключённый остаётся в списке, но не попадает в колесо. Состояние персистится.
- **✕ (удалить)** — полностью убирает участника из списка.

## Шаринг списка

Кнопка **«Поделиться»** (в шапке карточки) копирует ссылку с именами всех участников (`?users=[...]`). У того, кто откроет ссылку, список **заменится** на отправленный.
Детали — в [share-flow.md](./share-flow.md).

## Массовые действия

- **Очистить** (в шапке карточки) — удаляет **всех** участников и сбрасывает раунд/подиум.
- **Поделиться** — копирует ссылку с текущим списком.

## Визуальные состояния строки

- **Награды за раунд**: у занявших 1-е/2-е/3-е места рядом с именем показывается медаль 🥇🥈🥉 (слева, сразу после номера). Подробнее — в [round-and-podium-flow.md](./round-and-podium-flow.md).
- Отключённый вручную (`enabled=false`) — строка приглушена (`opacity`), веса недоступны.
- **Выбывший** за текущий раунд — имя зачёркнуто, бейдж **«выбыл»** (кроме награждённых — у них вместо бейджа медаль). При этом `enabled` **не меняется** (чтобы на следующий день не включать всех вручную).

## Счётчик

В шапке — **«Активных: X из Y»**: X = сколько человек реально участвует в текущем раунде (включены и не выбыли), Y = всего в списке.

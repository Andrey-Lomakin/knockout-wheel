# Флоу: Вращение колеса и выбивание

## Компонент колеса (`src/wheel/`, canvas)

- Сегменты строятся **пропорционально весам** участников (`×1`/`×2`): больше вес — шире сектор и выше шанс.
- Указатель (стрелка) зафиксирован сверху (12 часов).
- Анимация вращения с плавным замедлением (cubic ease-out); длительность задаётся пользователем.
- Победитель выбирается **случайно с учётом весов** (`pickWeightedIndex`), затем колесо доворачивается так, чтобы его сектор встал под указатель. Анимация лишь «раскрывает» предрешённый результат — честно, без влияния положения до спина.
- Актуальные значения читаются через `ref`/`useLatest` — анимация не «заедает» на устаревших данных.

## Старт вращения

1. Кнопка **«Крутить»** в центре колеса (доступна, когда активных ≥ 1).
2. Запускается анимация; **в центре на время спина показывается случайный зацикленный мем** (MP4 из `public/memes`).
3. В конце прошлый результат прячется, идёт новый спин.

## Победитель (1 последний участник)

Когда после выбивания остаётся **ровно один** активный участник, кнопка «Крутить» **меняется на мем** (зацикленное видео вместо кнопки) — крутить больше некого.

## Выбивание (конец спина)

После остановки (обработка в `src/game/model.ts` → `computeElimination`, вызывается хуком `useWheelGame`):

1. id выбитого добавляется в `eliminatedIds` — **`enabled` участника не меняется** (на следующий день не нужно никого включать вручную).
2. Считается `stillActive` (включённые и не выбывшие).
3. Кейсы результата подиума (см. [round-and-podium-flow.md](./round-and-podium-flow.md)):
   - `stillActive === 1` → остался один — это **1 место** 🥇, выбитый — **2 место** 🥈.
   - `stillActive === 2` → выбитый — **3 место** 🥉.
   - `stillActive === 0` → «Все выбыли».
   - иначе → «Выбит: <имя>», у победителя конфетти.

## Длительность вращения

- Селектор **3 / 5 / 7 / 13 сек** над колесом (`src/wheel/WheelControls.tsx`).
- Передаётся в колесо как `durationSec`; недоступен во время кручения.

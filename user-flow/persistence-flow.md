# Флоу: Сохранение данных (localStorage)

Код: `src/game/storage.ts`, `src/game/useWheelGame.ts`.

## Что персистится

- **Список участников** (`participants`) — включая id, имя, вес, флаг `enabled`.
  Запись — при каждом изменении. Это нужно, чтобы список переживал ежедневные запуски.

## Что НЕ персистится

- **`eliminatedIds` (выбывшие раунда)** — только в памяти. После перезагрузки все снова активны, без ручного включения.
- **`podium` (победители)** — только в памяти. Список победителей очищается при перезапуске страницы.

## Why

- Список людей стабилен: streamer добавляет участников один раз, и они не теряются.
- Результаты «сегодняшнего» раунда не должны «вечно висеть»; новый запуск = свежий раунд с тем же списком.

## Безопасность

- Чтение/запись обёрнуты в `try/catch` — приложение не падает в приватном режиме или при переполнении квоты.
- При чтении данные нормализуются (например, `enabled` приводится к `true`, если поле отсутствует), чтобы старые/битые сохранения не ломали UI.
- Счётчик id (`restoreIdCounter`) выстраивается по максимальному id в сохранении — новые участники не получают дубликаты.

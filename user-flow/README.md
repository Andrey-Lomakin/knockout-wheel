# Колесо выбивания — User Flow

Документация пользовательских сценариев (flows) приложения «Колесо выбивания».
Приложение: <https://andrey-lomakin.github.io/knockout-wheel/>

Детали данных и механики — в `src/game/` (состояние, storage, `model.ts`)
и `src/wheel/` (canvas-колесо, хуки анимации).

Обзор:

- [Управление списком участников](./participants-flow.md) — добавление, редактирование, веса, включение, шаринг, награды.
- [Вращение колеса и выбивание](./wheel-flow.md) — canvas, рандом по весам, мемы, победитель.
- [Авто-прокрутка](./auto-spin-flow.md) — автоматические спины с паузой до победителя.
- [Раунд и подиум](./round-and-podium-flow.md) — выбывание и медали в списке.
- [Сохранение данных (localStorage)](./persistence-flow.md) — что переживает перезагрузку.
- [Шаринг списка по ссылке](./share-flow.md) — `?users=[...]`, замена списка.
- [Плеер Яндекс Музыки](./music-flow.md) — встроенный iframe-плеер по ссылке на трек.

> Разделы «Известные ограничения» в конце флоу описывают реальное поведение как есть,
> а не желаемое, — чтобы документация не расходилась с кодом.

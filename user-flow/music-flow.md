# Флоу: Плеер Яндекс Музыки

Код: `src/lib/yandexMusic.ts`, `src/music/` (`useMusicPlayer`, `YandexPlayerFrame`, `MusicPlayer`).

## Старт

Карточка **«Яндекс Музыка»** находится в левой панели, над «Добавить участников».

## Вставка трека

1. В поле вводится ссылка на трек Яндекс Музыки, например:
   `https://music.yandex.ru/album/24223317/track/109407308?utm_source=web&utm_medium=copy_link` (utm не мешают).
2. Нажать **«Загрузить»** (или Enter).
3. Ссылка парсится → извлекаются `trackId`/`albumId` → строится iframe-плеер:
   `https://music.yandex.ru/iframe/#track/{track}/{album}`.
4. Поле и кнопка **скрываются**, показывается только **встроенный iframe-плеер**.

Ссылка **на альбом целиком** (без `/track/…`) тоже распознаётся — тогда строится
`https://music.yandex.ru/iframe/#album/{album}`.

## Сброс

- Справа в шапке карточки — кнопка **«✕»**: возвращает форму ввода (плеер скрывается, поле очищается).

## Внешний вид плеера

Плеер вставляется как компактный iframe **фиксированной высоты 90 px** на всю ширину карточки —
это стандартная «узкая» раскладка плеера Яндекса с обложкой и контролами. Прокрутки внутри области
нет, вся полезная часть плеера помещается целиком.

## Невалидная ссылка

Если ссылка не распознана — показывается сообщение «Ссылка не распознана. Вставьте трек из Яндекс Музыки»,
плеер не строится.

## Персистентность

Ссылка и плеер **не сохраняются**: после перезагрузки страницы карточка снова показывает пустую форму
(в localStorage лежит только список участников — см. [persistence-flow.md](./persistence-flow.md)).

> Примечание: Яндекс может ограничивать отображение плеера на произвольных/непроверенных доменах — тогда
> iframe может не показать трек, хотя форма/логика работают корректно.
